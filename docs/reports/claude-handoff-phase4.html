## 1. What this product is

**waapi** — unofficial multi-tenant WhatsApp HTTP API (Baileys) + React dashboard + static marketing site.  
Not affiliated with WhatsApp/Meta; ban risk disclosed. Brand via `BRAND_NAME`.

| Package | Role |
|---------|------|
| `apps/api` | Fastify `/api/v1` + internal admin `:3001` |
| `apps/worker` | Sessions, QR, send jobs, `WA_DRIVER=baileys\|fake` |
| `apps/dashboard` | Vite SPA (sessions, messages, settings, billing) |
| `apps/site` | Prerendered static HTML (Cloudflare Pages) |
| `packages/db` | Drizzle schema + migrations `0000`–`0010` |
| `packages/shared` | Zod schemas, plans, brand, error codes |

Stack: pnpm monorepo, Postgres 16, Redis 7, BullMQ, manual + Paddle billing (no Stripe).

### Q1–Q6 (summary — full evidence in pack-1 header)

1. **Invite atomic?** Yes — conditional `UPDATE … used_at IS NULL` inside register txn (`invites.ts`).
2. **Paddle raw + stale ts + account bind?** HMAC over `ts:rawBody`; stale ±5m rejected; checkout `accountId` from JWT → `custom_data` (route still JSON.stringifies parsed body — not byte-raw buffer).
3. **Trial expiry?** 402 `BILLING_EXPIRED`; grace then disconnect extras via queue; **keys not auto-revoked** by expiry alone.
4. **messages.upsert text?** Yes when present (`worker/.../manager.ts`); logs redact text; webhook payload purge via retention.
5. **Disconnect emails?** Not yet (WP-N). **Phone unique?** Yes — `sessions_phone_active_uidx`.
6. **Paddle events:** handled `transaction.completed` / `subscription.activated` / `payment_failed|subscription.past_due` / `subscription.canceled`; others ignored after idempotent ledger insert.
