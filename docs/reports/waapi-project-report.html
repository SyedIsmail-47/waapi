1. Executive summary

waapi is a pnpm monorepo that exposes a Fastify /api/v1 API and React dashboard for managing unofficial WhatsApp sessions (Baileys), outbound text send, HMAC-signed webhooks, invite-gated signup, trial + Paddle billing, and an internal admin CLI. A static marketing site (apps/site) is built for Cloudflare Pages.

Phases 1–3 (worker, API, dashboard) are shipped. Phase 4 closed-beta Tier-1 work packages A–G, J, L, M, N are merged into phase-4. Final PR phase-4 → main is open (#4). Empty branch phase-5-parity exists for the next phase. Tier-2 media/groups (H) and webhook event parity (I) are intentionally not started.

Product disclaimer: Unofficial client. Not affiliated with WhatsApp or Meta. Account ban risk is real and disclosed on the public site footer and legal drafts.

2. Goals of closed beta

  • Invite-only signup with Turnstile; terms acceptance stored at register.
  • Deterministic WA_DRIVER=fake for CI/e2e without live WhatsApp.
  • Trial billing (default 3 days, 1 session) with 402 enforcement when expired.
  • Paddle webhook verification on exact raw body; plan allowlist; manual review for refunds/pauses.
  • Ops: preflight env check, age-encrypted off-box backups, Origin CA nginx, runbook + Paddle go-live checklist.
  • Never log/store message bodies, tokens, or secrets in plaintext application logs.

6. Product features (what exists)

6.1 Auth & tenancy

  • Register / login / refresh / logout with JWT access + HttpOnly refresh cookie
  • CSRF double-submit on cookie-mode refresh/logout; production cookie Path=/api/v1/auth
  • Email verify + password reset (Resend/SMTP/console drivers)
  • SIGNUPS_MODE=open|invite|closed (default invite)
  • Terms checkbox → users.terms_version + terms_accepted_at
  • PATs and per-session API keys; account-scoped queries (tenant isolation tests)

6.2 Sessions & messaging

  • Create / connect / disconnect / logout / delete / rename
  • QR via Redis pub/sub; fake driver for CI
  • Send text with idempotency; plan warm-up + day/minute send counters
  • Disconnect alerts (email); unique phone → PHONE_IN_USE 409
  • Webhook endpoints with HMAC signatures; SSRF-safe URL checks; encrypted outbox

6.3 Billing

  • Plans in packages/shared/src/plans.ts (trial/starter/pro/enterprise)
  • States: trialing / active / past_due / canceled / expired + grace; paused flagged for review
  • 402 BILLING_EXPIRED on create/send when expired; billing GET + delete-account always allowed
  • BILLING_PROVIDER=manual|paddle only (no Stripe); no card data stored
  • 5-minute billing sweeper; admin CLI manual-review

6.4 Ops

  • pnpm admin — find user, suspend, set plan, revoke keys, force logout, invites, manual-review
  • pnpm preflight — production env gate (no secret echo)
  • scripts/backup-pg.sh / restore-pg.sh — age-encrypted dumps + sha256
  • deploy/nginx.conf — Cloudflare Origin CA, HSTS/CSP, CF real_ip ranges
