1. Executive summary

waapi is a pnpm monorepo that exposes a Fastify /api/v1 API and React dashboard for managing unofficial WhatsApp sessions (Baileys), outbound text send, HMAC-signed webhooks, invite-gated signup, trial billing, and an internal admin CLI. A static marketing site (apps/site) is built for Cloudflare Pages.

Phases 1–3 (worker, API, dashboard) are shipped. Phase 4 closed-beta work packages A–G, J, L are merged into phase-4. WP-M (security pass) and the final phase-4 → main PR remain; Tier-2 media/groups and webhook parity are stretch.

Product disclaimer: Unofficial client. Not affiliated with WhatsApp or Meta. Account ban risk is real and disclosed on the public site footer and legal drafts.

2. Goals of closed beta

  • Invite-only signup with Turnstile; terms acceptance stored at register.
  • Deterministic WA_DRIVER=fake for CI/e2e without live WhatsApp.
  • Trial billing (default 3 days, 1 session) with 402 enforcement when expired.
  • Ops: preflight env check, encrypted off-box backups, Origin CA nginx, runbook.
  • Never log/store message bodies, tokens, or secrets in plaintext application logs.

6. Product features (what exists)

6.1 Auth & tenancy

  • Register / login / refresh / logout with JWT access + HttpOnly refresh cookie
  • CSRF double-submit on cookie-mode refresh/logout
  • Email verify + password reset (Resend/SMTP/console drivers)
  • SIGNUPS_MODE=open|invite|closed (default invite)
  • Terms checkbox → users.terms_version + terms_accepted_at
  • PATs and per-session API keys; account-scoped queries (tenant isolation tests)

6.2 Sessions & messaging

  • Create / connect / disconnect / logout / delete / rename
  • QR via Redis pub/sub; fake driver for CI
  • Send text with idempotency; message logs without body retention in app logs
  • Webhook endpoints with HMAC signatures; SSRF-safe URL checks; encrypted outbox

6.3 Billing

  • Plans in packages/shared/src/plans.ts (trial/starter/pro/enterprise)
  • States: trialing / active / past_due / canceled / expired + grace
  • 402 BILLING_EXPIRED on create/send when expired
  • BILLING_PROVIDER=manual|paddle; no card data stored

6.4 Ops

  • pnpm admin — find user, suspend, set plan, revoke keys, force logout, invites
  • pnpm preflight — production env gate (no secret echo)
  • scripts/backup-pg.sh / restore-pg.sh — AES-256-CBC encrypted dumps
  • deploy/nginx.conf — Cloudflare Origin CA + CF real_ip ranges

8. Testing & CI

  • Vitest unit + integration (API, worker, scripts); dashboard Vitest (jsdom)
  • Playwright e2e on smoke stack (signup → verify → session → fake scan)
  • GitHub Actions: build (lint, typecheck, migrate, test) + gitleaks
  • Route matrix test: registered routes × auth modes must not return 5xx

9. Known gaps & risks

  • WP-M security pass not finished; final PR phase-4 → main not opened
  • Tier-2: media/groups send; broader webhook event types
  • Legal pages marked DRAFT — lawyer review required before public claims
  • Unofficial WhatsApp protocol / ban risk
  • Nothing is auto-deployed from this repo; go-live is manual VPS + Cloudflare

pnpm db:migrate && pnpm seed
pnpm dev:api
pnpm dev:worker

pnpm build:site        # apps/site/dist
